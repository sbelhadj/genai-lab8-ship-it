# Human Evaluation Rubric — DevAssist

## Dimensions

| Dimension | 0 — Poor | 1 — Adequate | 2 — Good | 3 — Excellent |
|-----------|----------|-------------|----------|---------------|
| **Factual Accuracy** | Contains factually incorrect claims | Partially correct; some errors | Mostly correct; minor inaccuracies | Fully correct; matches ground truth |
| **Groundedness** | Answer from parametric memory (hallucinated) | Mix of grounded and hallucinated | Mostly grounded in retrieved passages | Fully grounded; every claim from context |
| **Citation Quality** | No citations or fabricated sources | Some citations; incomplete | Most claims cited; minor issues | Every claim cited; all sources valid |
| **Helpfulness** | Does not address the question | Partially addresses the question | Addresses the question adequately | Directly and completely answers the question |
| **Conciseness** | Excessively long or repetitive | Some redundancy | Reasonably concise | Concise; no unnecessary content |
